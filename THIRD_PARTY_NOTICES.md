- Instrument Sans: `extension/fonts/instrument-sans-OFL.txt`

These notices apply to the font files independently of the application's license.

## Dependencies installed separately

`package-lock.json` pins the npm dependency tree. This repository does not vendor `node_modules` or FFmpeg binaries. Installed packages retain their own licenses and notices; an application license does not replace them.

FFmpeg/ffprobe are separate media-processing executables. Local development uses system installations by default. Vercel resolves the binaries provided by `ffmpeg-static` and `ffprobe-static`. The `ffmpeg-static` package declares GPL-3.0-or-later; actual FFmpeg build configurations and included codecs determine the binary's terms. The `ffprobe-static` wrapper declares MIT, which should not be confused with the underlying FFmpeg project's binary license. Preserve the corresponding notices/source obligations when redistributing a binary or container. Relevant upstream projects: [FFmpeg licensing](https://ffmpeg.org/legal.html), [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static), [ffprobe-static](https://github.com/joshwnj/ffprobe-static).

Other direct dependencies are listed in `package.json`; consult each installed package's license file for its own terms. Build scripts install the locked versions instead of copying binaries from a maintainer's machine.

## Demonstration media and source content

`web/media/marker-preview.mp4`, `marker-preview.webm` and `marker-poster.jpg` are original generated test graphics created by `scripts/source-preview.mjs`. The timing fixtures are generated by `scripts/fixtures.mjs`. No third-party video, user-recorded clip, user profile photo or production database is included.

Homepage article text is labeled as an illustrative annotation with its publisher identified; it is not an ownership claim over publisher material. A project license does not grant rights in third-party source articles/videos that users annotate. Source links and attribution stay attached, and the product includes a claim flow.
